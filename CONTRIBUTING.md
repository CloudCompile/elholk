# Contributing to Elholk

Elholk is an open-source LLM gateway. Contributions are welcome.

## Development
1. Clone the repo
2. `npm install`
3. Copy `.env.example` to `.env.local` and add at least Clerk keys
4. `npm run dev`

## Pull Requests
- Keep PRs focused and small.
- Run `npm run build` before submitting.
- Do not commit secrets or `.env.local`.
- Free tiers only; no paid/billing features.
